The pipeline includes data loading (NeuroDB), signal processing (NeuroAlgo), statistical analysis, and visualization (NeuroPlot).

## 2. Standardization Guidelines & Recommendations
To ensure long-term maintainability and consistency, the following naming conventions are recommended:

### Naming Conventions
- **Folders/Packages**: PascalCase or +PackageName (MATLAB style).
  - Example: `+NeuroDB`, `+NeuroAlgo`, `+NeuroPlot`
- **Classes**: PascalCase.
  - Example: `NeuroAnalyzer`, `Builder`
- **Functions**: snake_case.
  - Example: `compute_psd_simple`, `get_ancova_diff`
- **Scripts**: snake_case, preferably with a prefix indicating purpose (e.g., `pipeline_`, `demo_`, `run_`).
  - Current: `LFP_Analysis_ANCOVA_pipeline.m` (Inconsistent)
  - Recommended: `pipeline_lfp_ancova_dg.m`
- **Variables**: camelCase (e.g., `timeVec`, `psdResult`).

### Suggested Refactoring
- **Tool Folder**: The `tool` folder contains mixed naming styles and generic functions. Consider moving them to a package (e.g., `+NeuroTool`) or renaming them to `snake_case`.
- **Pipeline Scripts**: Standardize script names to start with `pipeline_` or `run_` for easy sorting.
